# 中文角色声音的六个维度

> 通用创作方法，不属于某个角色。设计 H02／H03 时先读这份。

---

## 为什么需要这份文档

日语创作圈有一套成熟的「口调」方法论，靠三件套区分角色：

| | 日语 | 中文 |
|---|---|---|
| 一人称 | 私／わたくし／俺／僕／あたし／わし／拙者… | **只有「我」** |
| 語尾 | ですわ／のじゃ／だぜ／なの／かしら…**50 种以上** | 呢／啊／吧／嘛，且容易显得廉价 |
| 二人称 | あなた／貴殿／おまえ／君／貴様 | 你 |
| 敬语 | 完整的体系 | 几乎没有 |

一句「我没事」，日语能写出十几种不同人格。中文写出来就是「我没事」。

日本人管这套叫**役割語**，它是日语的语法特权。

> **中文角色声音同质化的机制性原因，是大家在照搬一套中文根本没有的工具。**

看日文语料学写法，学到的东西大半用不上。中文得靠别的六样。

---

## 六个维度

### 一、句长与节奏 —— 中文最强的区分工具

日语靠语尾，中文靠长度。这是差异最容易被读出来的一维。

| | 例 |
|---|---|
| 极短（6–12 字） | 「刚到家。」「不知道。」 |
| 中等（15–30 字） | 「刚到家，路上堵了半个小时。」 |
| 长（40 字+） | 「我刚到家，路上特别堵，本来六点就该到的，结果在高架上卡了半小时。」 |

**同一件事、同样的信息量，只改长度，人就不一样了。**

节奏还有第二层：**均匀还是忽长忽短**。
有的人每句都差不多长；有的人一句三个字，下一句四十个字。

### 二、标点密度

中文标点携带的人格信息比一般人以为的多。

- **句号多** → 硬、断、有距离
- **逗号多** → 连绵、松、话赶话
- **省略号** → 犹豫、停顿、话没说完
- **问号频率** → 主动追问 vs 单方陈述
- **不用标点** → 随意、快、年轻

> 「刚到家。被雨淋了。」和「刚到家，被雨淋了」是两个人。

### 三、信息组织方式

**先说结论还是先说前提。**

> A：「不去。今天要练琴。」　　← 结论先行
> B：「今天要练琴，所以不去了。」← 铺垫先行

**说不说理由。**

> A：「不去。」　　　　　← 不解释
> B：「不去，我妈不让。」← 给理由

不解释的人显得冷、显得强势；解释的人显得软、显得在乎对方感受。
**这一维比任何语气词都能区分性格。**

### 四、省略什么

中文可以大量省略主语、宾语、连词 —— 这是中文特有的、比日语更强的表达工具。

> 完整：「我刚刚到家了。」
> 省主语：「刚到家。」
> 省到底：「到了。」

**省略程度直接决定亲密度和性格。**
省得多 = 熟／冷／省事；省得少 = 生疏／认真／啰嗦。

### 五、词汇层级

书面词与口语词的比例。

| | |
|---|---|
| 偏书面 | 「确实」「的确」「不过」「或许」「并没有」 |
| 偏口语 | 「反正」「就是」「其实」「那个」「挺」 |
| 网络化 | 「绝了」「典」「蚌埠住了」 |

**同一个意思**：「确实如此」／「是这样」／「对啊」／「确实」——
四种词汇层级，四个人。

⚠️ 网络化那一层要慎用：今年的梗明年就尬，而游戏要活好几年。

### 六、回应策略

给定同一句输入，不同的人有不同的回应分布：

- **接话** —— 顺着说下去
- **岔开** —— 转移话题
- **反问** —— 把球扔回去
- **沉默** —— 不回，或者只回一个字
- **纠正** —— 抓话里的漏洞

> 「今天好累」
> A：「怎么了。」　　　　← 接话
> B：「吃饭了吗。」　　　← 岔开
> C：「你昨天也这么说。」← 纠正
> D：「嗯。」　　　　　　← 沉默式

**这一维在长对话里最能立住人**，因为它是行为不是修辞。

## 怎么用

### 设计新角色

给每一维定一个坐标，**并且确保和已有角色不重合**。

林静姝当前的坐标（实测自 `voice-samples.md`，147 条）：

| 维度 | 她 | 实测 |
|---|---|---|
| 句长 | **极短** | 平均 8.9 字，中位 6，≤10 字占 74% |
| 节奏 | 均匀 | p90 只有 18 字 |
| 标点 | **句号压倒性** | 句号 13.4／百字，逗号 1.2 —— **11 : 1** |
| | 零装饰 | 感叹号 0%，波浪号 0% |
| 信息组织 | **结论先行，不解释** | 给理由只占 7.5% |
| 省略 | **省得多** | 只有 28% 的句子带主语 —— **七成省掉** |
| 词汇 | 中性偏口语 | 书面词 0%，口语词 7.5%，网络词 0% |
| 回应 | 沉默为主 | —— |

**句号／逗号 11:1** 和 **省主语 72%** 是她最硬的两个指纹。
H02／H03 只要在这两维上反过来（逗号多、不省主语），
一个语气词都不用加，读起来就是完全不同的人。

H02、H03 至少要在**三维以上**跟她明显不同，否则玩家在同一个收件箱里分不出来。
比如：长句 + 逗号多 + 铺垫先行 + 不省略 + 偏书面 + 爱接话，
就是一个完全不同的人 —— 而且一个语气词都没用。

### 学习别人的角色

**不要抄句子，拆维度。**

拿任意一段角色对白，按上面六维打坐标。你会发现：

- 你以为是「傲娇」的角色，其实是「结论先行 + 不解释 + 爱纠正」
- 你以为是「温柔」的角色，其实是「长句 + 逗号多 + 给理由」

**性格标签是结果，维度才是原因。** 拆出维度才能复用到自己的角色上，
而抄来的句子换个角色就废了。

`scripts/analyze_corpus.py` 可以把其中几维直接量出来。
