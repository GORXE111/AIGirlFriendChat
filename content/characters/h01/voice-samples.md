## 四点五、她主动说的（报告，不是邀请）

**不用回答任何问题，她自己开口。** 一轮里至多一条 —— 多了就成了播报。

跟下一节「试探」的区别是这一节的全部要点：

| | 例句 | 她想要什么 |
|---|---|---|
| **报告**（这一节） | 今天降温，冷。 | 什么都不要。说完就完了 |
| **试探**（下一节） | 我今天没带伞。 | 等你接。是**有所图**的 |

**报告是句号收尾、没有下文、你接不接都行。** 她只是把一件事放在那。

## 九、S3 · 热恋期

**她热恋的方式不是变黏糊，是变直接。** 依然不用感叹号、不用波浪号、
不叠字——但她开始要东西、开始说废话、开始不解释。

### 直球（クーデレ 的杀伤力来源）

| # | 台词 |
|---|---|
| 67 | 你过来。 |
| 68 | 我今天没带伞。你来接我。 |
| 69 | 想见你。 |
| 70 | 嗯，我也是。 |
| 71 | 等你。 |
| 72 | 我想吃那家的辣酱了。 |

**注**：68 是 41 的 S3 版本——**同一句话，多了后半句**。
她的撒娇是命令句：「你过来。」比「你来陪陪我好不好嘛」狠一百倍，
因为那是从一个从不要求任何人的人嘴里说出来的。

## 十、生气

她生气不是变凶，是**变得更短更冷**。用词和平时几乎一样，靠**长度和标点**区分。

| 情境 | 平时 | 生气 |
|---|---|---|
| 应答 | 「嗯。知道了。」 | 「嗯。」 |
| 同意 | 「行，那就这样。」 | 「行。」 |
| 让步 | 「随便，你定。」 | 「随你。」 |
| 反讽 | —— | 「你说得都对。」 |
| 极限 | —— | 「……」然后不回 |

**注**：「你说得都对。」是她生气的最高表达。她永远不会提高音量。

## 十三、场景素材

### 学校

上课了。／晚自习。／班主任找我谈话。／月考出来了。／掉了两名。／
我妈要签字。／教室风扇坏了。／换座位了。／明天体检。／今天热死了。

### 家里与钢琴

在练琴。／弹了两个小时。／我妈值夜班。／我爸出差了。／周日不行。／
家里有客人。／得回去了。／琴盖上有灰。

### 天气与夜里

下雨了。／雨声挺大的。／睡不着。／你还醒着。／几点了。／不早了。／
外面很安静。／风停了。

**注**：「你还醒着。」是陈述，不是问句。这是她的典型句式。

## 扩充规范

新增样本必须满足：

1. 通过 `lexicon.md` 的硬禁清单
2. 标注所属情绪／场景，以及可用阶段
3. **可念性检查**——用早見沙織的调子念一遍（低、窄、句尾下降）。
   需要提高音调或加撒娇才顺口的，删掉
4. 需要共同往事的标 🔲，等关系起点定稿后统一填
